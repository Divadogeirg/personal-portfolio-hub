# Personal Portfolio & Live Social Hub

A full-stack personal website built with Python (Flask) that showcases my Computer Science coursework and technical projects while dynamically integrating live status and content feeds from GitHub, Twitch, and YouTube.

## Features
* **Project Showcase:** Interactive portfolio displaying CS coursework, hardware/Verilog designs, and Python applications.
* **Live Social Hub:** Automated back-end integration checking real-time Twitch stream status, fetching recent YouTube uploads, and listing public GitHub repositories.
* **Responsive UI:** Clean, mobile-friendly layout with theme customization.

## Tech Stack
* **Back End:** Python, Flask, Requests, Python-Dotenv
* **Front End:** HTML5, CSS3, Vanilla JavaScript (Jinja2 Templating)
* **APIs:** GitHub REST API, Twitch Helix API, YouTube Data API v3
